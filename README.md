# AlertMind – AI-Assisted Mini Security Operations Centre

## Overview
AlertMind is a prototype Security Operations Centre (SOC) developed as an MCA capstone project. It integrates Wazuh SIEM with an AI-powered Tier-1 SOC assistant using LangChain and the Groq API (Llama 3.1).

## Features

- Wazuh SIEM
- 12 Custom Detection Rules
- MITRE ATT&CK Mapping
- AI-Assisted Alert Analysis
- Guardrails
- Prompt Logging
- Response Logging

## Technologies

- Python
- Wazuh
- Sysmon
- LangChain
- Groq API
- Llama 3.1
- VMware

## Disclaimer

This project is an academic proof-of-concept. The AI assistant provides advisory guidance only. All recommendations require review and approval by a human SOC analyst.
